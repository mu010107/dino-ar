DINOSSIER — INSTALAÇÃO NO GITHUB PAGES

1. Abra o repositório dino-ar no GitHub.
2. Apague ou substitua os arquivos antigos.
3. Envie estes três arquivos para a raiz do repositório:
   - index.html
   - style.css
   - script.js
4. Confirme o commit.
5. Aguarde aproximadamente 1 minuto e abra:
   https://mu010107.github.io/dino-ar/
